# System Workflows

## Customer Journey

### Registration & Onboarding
1. Sign up with email/social
2. Verify email address
3. Complete profile
4. Set preferences
5. Browse onboarding guide

### Shopping Process
1. Browse products
2. Apply filters/search
3. View product details
4. Select size/color
5. Add to cart
6. Continue shopping/checkout
7. Complete purchase
8. Track order
9. Receive order
10. Leave review
